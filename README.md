
# Lex Carwash

A Kenyan-inspired car wash landing page built with React, Vite, TypeScript, and Tailwind CSS.

## Overview

Lex Carwash is a modern brand site for a premium car wash and detailing business. The experience includes a strong hero section, service highlights, trust-building content, location details, and a clear call-to-action to encourage bookings.

## Tech Stack

- React 18
- Vite
- TypeScript
- Tailwind CSS
- shadcn/ui-inspired component patterns
- React Router
- TanStack Query

## Features

- Responsive landing page layout
- Branded Kenyan-inspired color palette and typography
- Service overview section
- Why choose us content
- Locations and contact callouts
- CTA-driven conversion sections

## Local Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open:

```text
http://localhost:8080/
```

## Production Build

```bash
npm run build
```

## Linting and Testing

```bash
npm run lint
npm run test
```

## Project Structure

```text
src/

  pages/          Route-level pages
  lib/            Utility helpers
  hooks/          Custom hooks

```
